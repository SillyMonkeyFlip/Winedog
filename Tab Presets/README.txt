WineDog tab presets

Each folder in here is one preset for Settings > Tab look on the site.
  - The folder's name is the tab name.
  - The picture inside the folder is the tab icon (png, jpg, webp, gif, svg or ico).

After adding, renaming or removing folders, double-click "Update Tab Presets.bat"
(in the main Winedog folder), then commit and push in GitHub Desktop.
